Welcome to JobTracker Hub

Pick (or create) a folder for this tracker. JobTracker Hub reads it in place — nothing is copied or moved — and everything you add or import here (resumes, cover letters, imported zips) lives inside that same folder.

  • Starting fresh? Click "New Folder" in the dialog that opens and create one inside Documents, or inside a cloud-synced folder (iCloud Drive, Google Drive, Dropbox, OneDrive) if you want it backed up automatically.
  • Already have a folder of applications, resumes, or a previous export? Point at that instead — you'll see a preview of what's in it before anything is linked.
  • You can add more trackers for other folders later, or import a tracker .zip, from the sidebar once you're in.
